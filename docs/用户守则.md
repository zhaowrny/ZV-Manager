## 一、软件性质与用途

1. ZV Manager（下称"本软件"）是一款 **Minecraft 服务器远程管理工具**，通过 RCON、SSH/SFTP 等协议连接到您**有权管理**的服务器，提供服务器控制、玩家管理、模组/插件管理、文件下载与远程终端等功能。
2. 本软件按"现状"提供，供个人或团队管理自有/受托管理的 Minecraft 服务器使用。

## 二、账号与凭据安全

1. 使用本软件需自行添加服务器连接信息（RCON 地址/密码、SSH 用户名/密码等）。
2. 您的连接凭据**仅保存在您的设备本地**（加密存储），本软件不内置任何云端账号系统，不会将您的凭据上传到开发者或任何第三方服务器。
3. 请妥善保管设备与凭据。因您主动泄露、设备被他人使用、系统越狱/Root 等原因造成的凭据泄露及后果，由您自行承担。
4. 建议仅连接您**拥有管理权限**的服务器；凭据应使用强密码，并定期更换。

## 三、合法使用（重要）

您承诺在使用本软件时：

1. **仅管理您有权管理的服务器**。严禁使用本软件连接、探测、控制任何未获授权的第三方服务器——未经授权访问计算机系统属于违法行为。
2. 遵守《中华人民共和国网络安全法》《计算机信息系统安全保护条例》及您所在地区相关法律法规，以及 Minecraft 最终用户许可协议（EULA）与相关服务器规则。

## 四、SSH / 终端功能风险提示

1. SSH 终端（Shell）拥有服务器**完全控制能力**。您在终端执行的任何命令（包括删除文件、重启系统等）后果由您自行承担。
2. 建议不要以 root 账户长期连接；对不熟悉的命令请先确认其作用。
3. 命令本地历史仅保存在您的设备上，可在应用内清除；本软件**不做任何云端记录**。

## 五、模组管理与下载功能说明

1. 下载功能数据来自 **Modrinth 公开接口**及其镜像线路（如 MCIM）。镜像线路由第三方维护，其可用性与安全性不由开发者控制。
2. 安装第三方模组/插件可能影响服务器稳定性（崩溃、冲突、性能下降）。安装前请备份重要数据，本软件提供的"依赖仓库"查询仅供参考，不能保证依赖关系完全准确。
3. 下载完成后自动上传至服务器的功能，依赖您配置的 SSH 连接，请确认目标目录无误后再启用。
